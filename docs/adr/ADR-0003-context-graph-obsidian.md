# ADR-0003: კონტექსტის გრაფი

## კონტექსტი

ძრავის პრინციპია ([[intent]] P2), რომ პროექტის კონტექსტი გრაფად იყოს გამოხატული — აგენტი უფრო ადვილად ორიენტირდება, თუ ხედავს, რა რას უკავშირდება (რომელ მიზანს ემსახურება სპეციფიკაცია, რომელ ADR-ს ეყრდნობა გეგმა, რომელ სესიაში გადაწყდა რა). შემოთავაზებულია Obsidian. პრობლემა: Obsidian-ის გრაფს მხოლოდ ადამიანი ხედავს — აგენტს ეკრანი არ აქვს; ხოლო თუ გრაფი ცალკე ბაზაში იქნება, ის ფაილებს ჩამორჩება.

## გადაწყვეტილება

1. **ერთი წყარო — თავად Markdown:** კავშირები იწერება `[[wikilink]]`-ებით და ფარდობითი `[ტექსტი](გზა.md)` ბმულებით, ტიპი და სტატუსი კი YAML frontmatter-ში (`id`, `type`, `status`, და ურთიერთობები: `intent`, `spec`, `adrs`, `supersedes`, `superseded_by`, `related`, `source`). frontmatter-ში ბმული ბრჭყალებშია (`"[[x]]"`), ზუსტად ისე, როგორც Obsidian-ს სჭირდება.
2. **ხედი მფლობელისთვის — Obsidian:** პროექტის საქაღალდე Obsidian-ის vault-ია; `.obsidian/graph.json` ტიპებს ფერებით ღებავს (ADR, სპეციფიკაცია, გეგმა, ეპიზოდი, დომენი…); `alwaysUpdateLinks` გადარქმევისას ბმულებს თავად ასწორებს. დამალული საქაღალდეები (`.claude`, `.git`) Obsidian-ში არ ჩანს.
3. **ხედი აგენტისთვის — `tools/context_graph.py`:** იგივე ბმულებიდან აგებს `memory/graph/graph.json`-ს და `CONTEXT-MAP.md`-ს; `query <id>` აჩვენებს ერთი კვანძის სამეზობლოს; `pending` — რა ელოდება მფლობელს; `brief` — SessionStart-ზე მოკლე ანგარიში.
4. **ერთი შემოწმება — `check`:** გატეხილი ან ორაზროვანი ბმული, frontmatter-ის შეცდომა, დაუშვებელი სტატუსი, id-ის დუბლიკატი, ჯაჭვის დარღვევა (CHAIN), ჩანაცვლების შეუსაბამობა (SUPERSEDE), დამტკიცება ჟურნალის ჩანაწერის გარეშე (LEDGER). ეს არის gate `graph` — pre-commit-შიც და Stop hook-შიც.
5. **ფაილის სახელები:** `ID-slug` (მაგ. `ADR-0003-context-graph-obsidian`); ბმული ფაილის სახელს ასახელებს (Obsidian ასე ხსნის), არა მხოლოდ id-ს. სახელები უნიკალურია, `README`-ზე ბმული — გზით (`[[memory/README]]`).
6. **„უცხო" ზონები** (`research/` — სხვა სესიების ან გარედან შემოტანილი მასალა): კვანძებად ჩანს, მათზე ბმული მუშაობს, მაგრამ მათ შიგნით ბმულებს არ ვამოწმებთ.

## განხილული ალტერნატივები

- **გრაფის ბაზა (Neo4j / vector DB / MCP სერვერი):** ძლიერია, მაგრამ ცალკე სერვერი, ცალკე სინქრონიზაცია და ყოველ შეტყობინებაზე ტოკენები. ფაილებს ჩამორჩება. უარყოფილია ამ ეტაპზე.
- **მხოლოდ Obsidian:** აგენტი ვერ დაინახავდა და ვერავინ შეამოწმებდა. უარყოფილია.
- **Obsidian-ის community plugin-ები (Dataview და სხვ.):** მოსახერხებელია, მაგრამ მესამე მხარის კოდია და აგენტისთვის უხილავი. ჯერ არა — შეიძლება მოგვიანებით, მფლობელის სურვილით.

## შედეგები

- \+ მფლობელი და აგენტი ერთსა და იმავე გრაფს ხედავენ, და ის ფაილებს ვერ ჩამორჩება — თავად ფაილებია.
- \+ გატეხილი ბმული commit-მდე და ტურის დასრულებამდე იჭერება.
- − ბმულებს დისციპლინა სჭირდება (სწორი სახელი, ბრჭყალები frontmatter-ში); შეცდომას gate მაშინვე ამბობს.

## დადასტურება

დრილი: სუფთა fixture გადის; გატეხილი ბმული, უბრჭყალო frontmatter-ბმული, დაუშვებელი სტატუსი, id-ის დუბლიკატი, ჟურნალის გარეშე დამტკიცება და ჯაჭვის დარღვევა თითოეული ჩავარდნით მთავრდება; ცარიელი საქაღალდე — INCONCLUSIVE (exit 2) და არა PASS.
