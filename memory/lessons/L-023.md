# L-023 — A document names the file a check lives in

**What happened.** ADRs, process.md and README said the new orchestration cases were "in the drill" while they lived in
a scratch folder that no commit check ran — a reader would have trusted a gate that did not exist (caught by the session
itself before the merge, 2026-10-18).

**Guard.** None.

The rule is this lesson's line in [[LESSONS]].
