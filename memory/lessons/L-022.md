# L-022 — The engine's Linux runs went through WSL, and three things bite

**What happened (2026-10-18).** wsl.exe reorders a script's stdout and stderr; Git Bash rewrites the `/mnt/c/…`
argument; a worktree's `.git` file points at a `C:/` path, and files copied from `/mnt/c` arrive with every execute bit
set.

**What works.** Start the script with `exec 2>&1`; prefix `MSYS2_ARG_CONV_EXCL='*'`; copy the folder into the Linux
home and run there, with `git config core.fileMode false` in the copy only.

**Guard.** None.

The rule is this lesson's line in [[LESSONS]].
