# L-007 — Another session may be working in this folder

**What happened.** A parallel session's prototype folder sat in the project (2026-09-18); committing or moving it would
have taken another session's work.

**Guard.** None: the Stop gate checks only this session's touched files, and the guard does not cover foreign folders.

The rule is this lesson's line in [[LESSONS]].
