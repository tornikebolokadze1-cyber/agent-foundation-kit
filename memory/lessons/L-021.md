# L-021 — Random test data can match a neighbouring check

**What happened.** The dispatcher's drill seeded a random OpenRouter key; about one run in ten its 64 hex digits held an
11-digit run, the personal-number pattern matched first, and the case read PERSONAL DATA instead of SECRET — red on
Linux on unchanged code, green on Windows by luck (2026-10-18). The decision: a credential wins, so the person is told
to rotate it.

**Guard.** The drill's `decision` group — the digit-key case; the old order is a caught mutant. This template has no dispatcher code, so its drill
leaves that group out.

The rule is this lesson's line in [[LESSONS]].
