# L-012 — A subagent's research conclusion without a primary source does not go into a document

**What happened.** A direction claimed by a research subagent turned out reversed and was caught only by an independent
second check.

**Guard.** None — a source label is documentation, not a check.

The rule is this lesson's line in [[LESSONS]].
