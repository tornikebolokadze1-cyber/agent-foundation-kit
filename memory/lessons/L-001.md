# L-001 — Georgian output on Windows

**What happened.** Python on Windows defaults to cp1252; a hook printing Georgian died with UnicodeEncodeError and the
context injection silently vanished.

**How we know.** The drill's episodic injection test prints Georgian, so a hook that loses UTF-8 fails there.

The rule is this lesson's line in [[LESSONS]].
