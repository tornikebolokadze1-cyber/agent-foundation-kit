# L-016 — The engine is judged by a new user's journey, not by its documents

**What happened.** Asked to strip a project's traces, a turn went into polishing documents; the engine author meant something
else — a person installs the engine, writes an idea and is led through every stage (2026-10-11). One real session in a
fresh copy with an idea as its first message showed the actual gaps in six steps for $0.39.

**How to run it.** A real `claude -p` session with `CLAUDECODE=` and `EPISODIC_AUTOSUMMARY=0`; `EPISODIC_NESTED=1`
switches the injection off.

**Guard.** A live session in a fresh copy, run by hand (ADR-0011; 2026-10-11: a bakery-website idea reached a
specification in four turns without a setup question).

The rule is this lesson's line in [[LESSONS]].
