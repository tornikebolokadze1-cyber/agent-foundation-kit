# L-017 — The author's machine hides what a new user's machine lacks

**What happened.** The drill passed on the author's machine because gitleaks was installed; a review found that on a machine without
it four secrets cases would read DEAD (2026-10-11), and a fresh copy showed the commit checks switched off. Again
2026-11-08: this template's first by-hand drill run found the permission-window case DEAD — the drill expected an ask
rule for the dispatcher, which exists in the engine's own copy and not in this template. The drill now asks for that
rule only in a copy that has the dispatcher (two mutants caught).

**How to hide the author's tools.** `PATH` without the tool's folder, `HOME` and `USERPROFILE` pointing at an empty folder.
Hiding a tool by dropping its PATH folder also drops whatever shares that folder (Scoop's shims, Homebrew's bin,
/usr/bin) — inside the drill, swap the one function that searches for it instead.

**Guard.** The drill: its own gitleaks search decides which scanner the secrets cases expect, so the same drill passes on
both kinds of machine and catches a silent fallback; the dispatcher's window case has a control for a copy without the
dispatcher. The whole-drill run with the author's tools hidden is manual.

The rule is this lesson's line in [[LESSONS]].
