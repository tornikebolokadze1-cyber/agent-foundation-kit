# L-018 — Two texts that name different sources for one step make the agent pick one at random

**What happened.** Four live journeys (2026-10-12) found the stage block saying "ask §7's questions" while the
guide said "ask §1's", and the stage note saying "switch lint and unit on first" while gates.toml and the guide said
"unit with the first test"; the approve skill said "offer a commit", so every approval cost a turn of "shall I save?".
Each journey followed a different text.

**Side note.** `total_cost_usd` in `claude -p --resume` JSON is the session's running total, not the turn's.

**Guard.** The drill pins the stage texts (11 mutations caught); since 2026-11-09 its `wiring` group also keeps
each guide's code folders (`code:` in its frontmatter) inside the code rule's `paths` (6 mutants caught) — the audit of
2026-10-31 found the rule missing the folders the guides build the student's code in. The rest of the skills and guides
is not machine-checked.

The rule is this lesson's line in [[LESSONS]].
