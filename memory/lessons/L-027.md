# L-027 — A permission rule covers the tool it names, and no other

**What happened.** The project's ask list and its shell deny rules were all written as `Bash(...)`. On Windows Claude
Code has a second shell tool, PowerShell. In the 2026-11-09 audit a probe session ran `git stash list` through that
tool with no window, while the same command through Bash was stopped by the ask rule: the list did not name the tool.
The guard reads a PowerShell command too — its own mode for that shell, with its cases in the drill's `guard` group —
so the hard refusals did not hang on the lists (no live probe ran a refused command through PowerShell). What had no
twin was every "ask the owner first" rule — installs, deletions, push and merge.

**How we know the rule is right.** Probes on Claude Code 2.1.321, read from each session's stream (the init event's
tool list, the tool_use blocks, permission_denials) and recorded with the engine's live probes: with the tool
offered, the command ran through PowerShell and was denied through Bash; with `"PowerShell"` on the deny list the tool
is not offered with the switch set (`CLAUDE_CODE_USE_POWERSHELL_TOOL=1`), with the flag (`--allowedTools PowerShell`),
or with both. Monitor, the third tool that starts a command, was probed as well: a `Bash(...)` rule and the guard's
hook both reach it — what Claude Code's tools reference says (read 2026-11-10), now measured.

**What narrowed it.** The tool was off by default here: with the engine's settings and `--allowedTools Bash` it was
not offered. Claude Code's tools reference (read 2026-11-10) gives the reason — where Git Bash is installed, a Bash
deny rule in a settings file switches PowerShell off — so the hole needed someone to switch the tool on (how the
audit missed that is L-028). The deny line makes the answer independent of that default.

**Guard.** The drill's `wiring` group: the deny list must switch every shell tool other than Bash off by name — a list
without the line, and a list with a one-command rule in place of the name, both go DEAD. Not guarded: a tool that
starts commands and arrives with a later Claude Code version; comparing a session's tool list with the tools the
lists cover is a proposal, not a check.

The rule is this lesson's line in [[LESSONS]].
