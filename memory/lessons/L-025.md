# L-025 — One folder, several spellings

**What happened.** The kit's CI went red on macOS and on the Windows runner while every local run was green
(2026-10-19): the sentinel resolved the project root (`/private/var/…` on macOS; the long name behind a runner's 8.3
`RUNNER~1` TEMP path), but a Grep's output keeps the name the folder was given, so a `research/` line went
unrecognised. The author's own TEMP has no second name, so no local run could show it.

**Guard.** The drill's sentinel and (since 2026-10-23) gates groups — folder-link cases and a nested-name case on
macOS/Linux, mutation-caught.

The rule is this lesson's line in [[LESSONS]].
