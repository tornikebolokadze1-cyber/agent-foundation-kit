# L-003 — Git Bash rewrites slash arguments

**What happened.** `claude -p "/approve …"` from Git Bash turned into `C:/Program Files/Git/approve`.

**Why not the other switch.** `MSYS_NO_PATHCONV=1` also stops the conversion of environment variables, so a POSIX path
in an env var reached Python as a doubled Windows path and a stray folder appeared there (2026-09-19).

**Guard.** None.

The rule is this lesson's line in [[LESSONS]].
