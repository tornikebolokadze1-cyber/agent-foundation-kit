# L-005 — Never touch global git config

**Why.** Global git config belongs to the person, not to the project; a project configures its own repository only.

**Guard.** The project's ask rule `Bash(git config*)`: every git config change waits for the owner. The drill's
`wiring` group checks that a `git config` command still asks (ADR-0015).

The rule is this lesson's line in [[LESSONS]].
