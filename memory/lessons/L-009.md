# L-009 — A stub proves the stub

**What happened.** The drill's summarizer ran through a stand-in, so it never noticed that the `claude` on Windows' PATH
was a broken npm shim — every real auto-summary from a VS Code session would have failed. Only a live `claude -p`
session in a copy of the project found it.

**Guard.** The drill's summarizer-binary cases (`episodic` group) and a live run, which is done by hand.

The rule is this lesson's line in [[LESSONS]].
