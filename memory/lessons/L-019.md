# L-019 — A drill's timing margin is measured on a loaded machine

**What happened.** The status line's kill test gave the child 2 s; with ~1000 processes running, `taskkill` alone took
2.2 s and the case failed on unchanged code (2026-10-12). A drill that started before midnight expected the episode of
the old date.

**Guard.** The drill: the kill case waits 10 s, and a mutation is still caught. The date case: none.

The rule is this lesson's line in [[LESSONS]].
