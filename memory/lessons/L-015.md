# L-015 — Strong-safeguard models flag defensive guard-hardening as cyber-offense

**What happened.** Opus 5.5's safety filter marked a guard-hardening session of the engine `[cyber]`, killed the
correctness critic mid-run and cut a response; the work continued on Opus 4.8. It recurred 2026-10-11 (the security
critic on Opus 5.5; done on Sonnet) and 2026-11-01 (Fable cut a reply that quoted drill.py's bypass labels).

**How to work.** Prove guard and bypass fixes with mutation tests (break and catch); keep exploit payloads in code and
drill files, never in prose; leave drill.py out of scans you print. When a critic is blocked, the machine check is the
stronger evidence (ADR-0006).

**Guard.** None — platform behaviour.
