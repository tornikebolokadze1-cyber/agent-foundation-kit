# L-011 — Two sessions in one folder share the next number, the branch and the IDE bridge

**What happened.** Two parallel sessions took ADR number 0007 at the same time, and one session's commits landed on the
other's branch, because the branch pointer is shared by the whole folder (2026-09-25).

**What happened again — the editor (2026-11-08).** Two conversations ran in one VS Code window, one
from 03:30 and one from 03:32. The extension's `/ide` bridge keeps one client — its log shows
"Disconnecting previous WebSocket client" twice at 03:32:23, 5 ms apart — and `netstat -ano` showed the port's only
connection owned by the other conversation's `claude.exe`, so the second conversation's `/ide` failed. The first fix
handed to the engine author reopened the session with `claude --continue`, which opens the folder's newest conversation — with
two alive, possibly the other one; the same day it was corrected to `claude --resume <id>`.

**Guard.** None.
