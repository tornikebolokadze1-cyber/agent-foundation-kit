# L-010 — Real use is a test the drill cannot run

**What happened.** Three days of normal use showed that VS Code opens Claude Code sessions in which nothing is said
(often two in the same second); each left an empty episode — 9 files and a 7-item reconcile list of pure noise. An empty
session (no transcript, untouched stub) now leaves no trace (the engine author's decision, 2026-09-22).

**Guard.** The drill's empty-session cases (`episodic` group).

The rule is this lesson's line in [[LESSONS]].
