# L-020 — A missing brief is an alarm

**What happened.** A resumed session (2026-10-16) came from a Claude Code process whose PATH lacked the Python folders:
every hook went through `py.sh`, found no Python and exited 1 — the guard and the sentinel were off, no working memory
arrived, and the agent was told nothing (the person sees hook errors; the model does not). Only the commit check's
`PY-MISSING` showed it.

**What to do.** Run `bash .claude/hooks/py.sh --version` before any work; if Python is missing, tell the person
(restart VS Code or the terminal) and put the Python folders on PATH meanwhile.

**Since then the guard fails closed** (2026-11-01): with Python missing or the guard itself failing, every tool
stops — `GUARD[X1]`/`[X2]` or the hook's `onFailure: block` — so the silence of 2026-10-16 cannot recur; reopening the
terminal or VS Code is the way out.

**Guard.** After the fact: the episode notes a failed or missing SessionStart (drill). Live: none.

The rule is this lesson's line in [[LESSONS]].
