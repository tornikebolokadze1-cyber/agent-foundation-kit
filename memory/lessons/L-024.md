# L-024 — A mutation MISS can mean an incomplete battery, not a redundant fix

**What happened.** In the critic-round guard hardening (2026-10-19) a mutant MISSED a reverted check (`COMPUTED_RE` →
`HIDDEN_WORD_RE` in `git_hides_option`); the agent read the MISS as "redundant" and kept the revert. An independent refuter traced
that the revert reopened a hook bypass: a shell glob character placed inside a git option after its leading dash, or
inside the subcommand's name, which the shell expands into the real option or command. `HIDDEN_WORD_RE` matches a glob
character only at a token's start, and git options begin with `-`. The "0 flips" verdict came from a battery with no
glob-inside-a-git-option case. (The exact forms live in the drill, not in prose — [[L-015]].)

**Guard.** The drill: the three glob positions in `git_hides_option`, each mutation-caught.

The rule is this lesson's line in [[LESSONS]].
